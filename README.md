# 🧮 Simple Calculator in Java

This is a basic Java console-based calculator program that performs simple arithmetic operations such as:
- Addition
- Subtraction
- Multiplication
- Division

The user enters two numbers and selects an operation. The result is then displayed on the console.

---

## 🚀 Features
- User-friendly console interface
- Uses `Scanner` for input
- Uses `switch-case` to choose operations
- Handles division by zero
- Easy to understand and modify

---

## 🛠 Technologies Used
- Java
- JDK 8 or above
- IDE (IntelliJ / Eclipse / NetBeans / VS Code) or Command Line

---

## 📌 How to Run the Program
### **Using Command Line**
```bash
javac Calculator.java
java Calculator
